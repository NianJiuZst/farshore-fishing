# 海洋场景视觉检查

2026-10-04，使用原生Godot4.6.3 Mobile/Vulkan，经私有X显示和Mesa llvmpipe桌面软件渲染检查。不是Android手机的帧率、功耗、安全区或触控验收。

三个新GLB分别提供火山岛礁、冷色陆架海崖、暖色珊瑚环礁。六钓点使用既有船台；远洋机位移到岛礁外侧，保留连续海天线。所有新环境几何由 `tools/art3d/build_ocean_environment.py` 原创生成，Blender主文件在 `art_masters/3d/region_*_ocean.blend`；运行依旧使用已归档许可的原Poly Haven表面纹理和天空。

检查生成3张1600×900旅行预览卡，以及全部6点在720×1280和720×1584的12张真实运行截图。预览卡从同一套真实3D场景截取，没有用外部照片替代运行画面。快照在 `docs/evidence/1.3.0/ocean-world/`，原始卡片在 `game/assets/scenery/`。

发现并修复：

- 有限范围的旧海岸反射探针在开放海面形成矩形反射边界。仅新海洋水域改用连续天空反射，既有6水域保持原逻辑
- 新岛屿中心的高度噪声导致尖窄裂缝；中心封口和径向收敛已修复并重渲染
- 棕榈树的根部最初未使用岛面高度，已按局部地形放置；细叶宽度调整后保留闭合真实叶片网格

检查所用隔离世界工程复制生产stage、shader、世界数据、环境/人物资源和字体。只移除独立工程的默认Main入口，显式运行 `capture_ocean_views.gd`；未复制玩家存档，也未改动主源码。渲染输入哈希保留在证据目录。渲染期间鱼类清单的嘴部标记随后细调，因此那一份未显示的鱼类注册表哈希不同于最终值；本轮世界画面没有实例化任何鱼，不能作为鱼类动画验收。完整Main和所有鱼的最终集成验证另行记录。

检查确认6场景能够加载，船与钓手的位置一致，近岸/远洋视角和三个水域色调有区别，两种竖屏保持水平构图，没有海面拼接边、岛面孔洞或缺失区域资源。天空、天气和用户新增的画质控制继续使用原实现。未把无人海面截图当成完整游玩或手机性能证据。
