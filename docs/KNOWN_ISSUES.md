# 已知边界 · 1.2.0

## 本次设备验证边界

- 未连接用户的 ARM64 Android16 真机。具体手机的安装限制、触感、音效输出、刘海/挖孔安全区、长时间发热与电池耗用需要用户验收
- 本版面向用户指定的 Android16 / 骁龙8 Elite，使用 Mobile Vulkan。桌面软件渲染与 x86 模拟器的帧率不能代表该 ARM64 手机；尚未据此承诺帧率、触控延迟或长期温度表现
- 未提供云存档；卸载或清除数据会丢失本地进度。覆盖升级须延续包名和签名
- 存档有备份、内容校验与失败重试；未做真实断电/闪存故障注入，不声称跨平台绝对原子性
- 44种鱼使用本项目制作的真实网格、骨骼和动画；固定人物基于 MakeHuman Community CC0 图形资产，经本项目适配和制作钓鱼动作。物种形态经过资料核对与多角度审查，仍是游戏化造型，不替代专业鉴定。图鉴列表插画和界面图标含图像生成工具辅助素材，游戏数值不代表实测科学模型
- Godot4.6.3 Mobile 的 ReflectionProbe 在桌面软件 Vulkan 退出时存在已复现的七个 Texture RID 清理警告。六轮创建/释放试验未观察到资源计数增长，但不是长期 Android 内存保证；保留完整证据于 3D_ACCEPTANCE.md，未过滤警告或降低渲染质量来隐藏它

- 自动搭配浮漂钓组覆盖全部游戏钓点与饵类，是有意的玩法简化；研究资料不支持把一套现实浮漂钓法泛用于所有深海水深、路亚与鱼种。送漂、顿沉或横移均不能被当作现实中必中的规则

- 已修复并保留回归测试：逃脱返回锁死、保存失败退出、选择保存失败状态回滚、重复保存按钮、旧会话结果覆盖、深水钓点装备降级、终态暂停返回
