# 已知边界与后续计划

## 本次设备验证边界

- 未连接用户的 ARM64 Android16 真机。具体手机的安装限制、触感、音效输出、刘海/挖孔安全区、长时间发热与电池耗用需要用户验收
- 桌面与软件模拟器的帧率不能代表中档手机性能。30FPS 为目标基线，不能据此承诺所有设备达标
- 未提供云存档；卸载或清除数据会丢失本地进度。覆盖升级须延续包名和签名
- 存档有备份、内容校验与失败重试；未做真实断电/闪存故障注入，不声称跨平台绝对原子性
- 插画为 AI 辅助创作且经过形态校对，适用于自然题材游戏，不替代专业鱼类鉴定；游戏数值不代表实测科学模型

## 已解决的开发问题

- 导出目录误配置导致工作目录被清理：所有生产脚本/数据已恢复，所有72张鱼/场景运行图片从独立底稿恢复并核对哈希。恢复后全套42,012核心断言与201存档断言重新通过
- 当前使用Git版本记录、独立完整快照、哈希清单、一次性副本打包和规范Android导出目录。导出器不再直接操作源工程
- 已修复并保留回归测试：逃脱返回锁死、保存失败退出、选择保存失败状态回滚、重复保存按钮、旧会话结果覆盖、深水钓点装备降级、终态暂停返回
