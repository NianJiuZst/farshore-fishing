# 画面、交互与进度保护 · 未发布工作版

本轮在 1.2.0 源码上优化，沿用 Godot 4.6.3、Mobile Vulkan、44 种鱼、六个地区和十二处钓点。没有改动物种 ID、钓获尺寸算法、读漂判定、装备成长数值或结算奖励。安装包身份和版本号仍是原发布值；后续打包时需单独提升版本并使用原签名。本文件描述工作区行为，不代表发布或 Android 设备验收。

## 画面与操作

- 启动时分阶段展示内容检查、读取进度与场景准备，内容校验失败仍阻止钓鱼。
- 首页采用风景背景、明暗渐变与集中操作区。菜单、图鉴、结果页使用一致的纸色卡片、输入框、焦点边框和大触控按钮。
- 页间淡入与按钮按压反馈可在设置中关闭；手机安全边距、滑动取消点击、暂停和返回逻辑继续保留。
- 各水域使用不同的空气色、清澈度和粗糙度。新增两层低成本远景地形，日间、黄昏和天气变化的光照平滑过渡。
- 水面按视距减少细碎法线，统一两组落水扰动的位移与法线；水面不再接收树叶的生硬面片阴影。岸边泡沫和潮湿过渡更细碎，岩岸机位附近树冠不再遮住观察视线。
- 人物保留原真人比例模型与骨骼，对衣料、皮肤、轮廓补光和钓轮摇柄进行表现优化。摇柄受实际收线驱动，竿形缓存减少重复网格构建。
- 省电 / 均衡 / 精致三档控制阴影、抗锯齿和装饰效果；省电最高 30 帧，其余最高 60 帧。三档均保留可读的原生分辨率与浮漂必要动作，不降低钓鱼判定精度。
- 渲染模块保留清晨、夜间调光接口供未来扩展，当前游戏出鱼条件仍使用既有日间 / 黄昏循环。

实现遵循 [Godot 4.6 Mobile 渲染器能力](https://docs.godotengine.org/en/4.6/tutorials/rendering/renderers.html)，没有开启该渲染器不支持的 SSR、SSAO 或体积雾。触控布局参考 [Black Salt Games 的移动端设计分享](https://developer.apple.com/videos/play/meet-with-apple/247/) 和 [Android 触控目标指南](https://developer.android.com/guide/topics/ui/accessibility/views/apps-views)。参考用于设计原则，没有引入其他游戏的素材。

## 声音与钓鱼反馈

水声、流水、风、雨、收线和泄力六层声音按场景混音；抛竿、实际落水、中鱼、起鱼、脱钩与放归使用固定大小的独立音效池，避免彼此截断。声音由 `tools/synthesize_audio.py` 确定性生成，没有外部录音样本。暂停会停住声音与触觉，失败提示允许已经开始的短尾音自然结束。

预判前的 `WAITING / NIBBLE / BITE` 不会通过声音、震动、按钮变色或新增镜头动作泄露鱼是否真正含饵。只有浮漂给出读漂信息；搏鱼阶段才使用可见张力和冲刺强度控制声音与节制触觉。

## 旧进度与手动备份

自动存档仍使用原 `user://` 命名空间、文件名和 schema 2，兼容 schema 1。数量、首次/最近钓获、独立最长与最重个体、已拥有装备、解锁地区、收藏、待处理钓获和兼容扩展字段均保留。

设置 → 备份与恢复进度：

1. 点击“生成当前进度备份”，复制全文，保存到游戏外的个人笔记或文件。
2. 在需要恢复的安装中粘贴全文，点击“检查并预览恢复”。
3. 检查鱼种数量、累计钓获、旅币和待处理钓获，再确认替换。
4. 如需撤销，打开“查看恢复前的进度”，预览并恢复该快照。

新备份封装包含 SHA-256 完整性校验，用于发现文本意外改动，不是加密或防作弊。旧版原始 JSON 也可读取，界面会标明没有完整性校验。恢复前先验证格式、已知内容引用和当前修订号，再写入并回读恢复前快照；写入失败不更新内存状态。未来版本、保护模式、未知资源引用和正在进行的一竿不能被恢复覆盖。保护模式不会把默认空进度伪装成可用备份。

覆盖更新保留进度要求包名和签名一致；卸载或清除数据会删除应用私有存档。手动备份只有保存到应用以外才可在卸载后使用，本轮没有云存档，也不能自动访问另一个 Android 包名的私有数据。

## 开发边界

原模型与高清鱼图继续使用既有来源和许可。新增测试脚本、测试数据、截图和运行日志留在仓库外的任务工作目录，不作为游戏源码提交。发布前仍需原签名 APK 的实际覆盖安装、Android 真机帧率、触控、温度和触觉验证。
