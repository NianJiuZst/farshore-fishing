## 蓝鲸的独立可完成玩法

在太平洋远洋蓝水航线进入「鲸影共鸣」。三阶段依次为按住/松手连起三道光环、左右跟随潮流、按住/松手维持能量张力。各阶段有可见绿带、进度和时间；暂停、取消、失败重试和保存失败重试均经过真实 Main 集成验证。基于可观察状态的自动操作能在 25.4 秒完成，这不代表普通玩家操作时间。

独立舞台使用 26 米蓝鲸与 5.6 米船作参照，镜头包含全身；水平尾叶上下摆动，能量线连接前方光环，成功后留在水中自由游动。挑战不使用鱼饵、嘴部鱼钩、普通起鱼落地、出售或鱼获奖励。独立完成次数、首次、最近和最快时间写入原 schema 2 的可选扩展；旧存档首次加载时扩展为空。

蓝鲸自然史明确其须鲸哺乳动物身份、滤食磷虾、保护状态与现实观察边界。幻想体长、近距离镜头与能量连线另行注明。详见 [蓝鲸操作与验证说明](BLUE_WHALE_CHALLENGE.md)。

## 资料与素材来源

自然史采用逐字段来源，缺乏可靠最大体重时保留 `null`。稳定 ID 不随学名历史组合改变。各海真实分布、栖深与尺寸量法经 FishBase、NOAA、MBARI、国家渔业机构与研究来源核查。见 [原三海 24 种资料](OCEAN_DIVERSITY_SPECIES_SOURCES.md) 和 [红海 12 种资料](RED_SEA_SPECIES_SOURCES.md)。

37 张插画均由本任务独立调用内建 ImageGen 生成并逐张审查，属于写实生成插画，不冒称实拍照片。保留原始生成文件、透明主图、游戏图、缩略图、提示词、端点、逐文件 SHA256 与导入 RGBA8 审计。旧 74 张素材及其清单条目保持原值。见 `art_masters/fish_photoreal_diversity/asset_manifest.json`。

37 个立体模型由原创参数化网格、每物种 JSON 源和 Python 生成器制作；不借用旧模型放大、不宣称这些新素材有 Blender 主文件。所有 37 个模型已逐字节重建，111 个新旧模型通过二进制校验；37 个实际 Godot 导入骨骼与 222 张原生 GPU 帧已验证。见 [模型与动画审查](ASSETS_3D_OCEAN_DIVERSITY.md) 和 `ASSETS_3D_OCEAN_DIVERSITY_PROVENANCE.json`。
