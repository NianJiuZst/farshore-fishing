# 1.3.0 海洋扩展 · 开发记录

基线是用户已更新的 `1afda37fa9fd8be23ff6d5cef1790a008a44f5f6`，保留其光照、水体、人物、触控、环境音、画质和备份恢复实现。开发中的源码备份位于独立 `ocean-expansion` 分支；本记录不代表 APK 已发布。

## 内容范围

- 保留原44种鱼及历史标识，新增30种，合计74种
- 太平洋、大西洋、印度洋3个虚构复合水域及6个船钓点，合计9地区18钓点
- 每种新增鱼独立3D体形、材质、骨骼四动作，独立高清生成写实插画，以及有字段级来源的离线自然资料
- 大洋钓点是不同海区的虚构合辑，不暗示跨洋鱼种在同一真实地点共同分布
- 大型鲨鱼只作虚拟保护观察与放归；游戏不是现实捕捞法规或操作指南

## 尺寸调校

原44种鱼的常规上段保持原值，新设 `normal_max_mm`。98%的抽取使用 `u^1.55`（原为`u^1.9`），2%进入常规上段至虚构最大值的尾部，尾部使用`u^2.6`。游戏重量继续采用独立锚点的立方模型及0.91—1.09体况倍率；它不是科研体长—体重关系。

理论巨物比例从6.5067%增加至9.7581%。原44种鱼的平均长度按各自范围增加5.45%—10.71%，平均相对增加8.07%。这仍是物种条件下的游戏个体分布，不是每竿必定钓获概率。

初轮880,000次真实GDScript抽取中，巨物85,817条，超过常规上段15,735条；1,760,225项断言通过。2%是进入扩展分支的概率，整数毫米舍入后实际严格超过上段的个体略少。最终74鱼结果将在完整集成后另记。

原百科资料中的自然最大长度、最大重量、量法、原始来源及其不确定性均不修改。游戏最大值允许超过这些记录，界面明确说明为虚构游戏极限。若来源量法为叉长、标准长或未注明，数值仅用于游戏创作参考，不宣称与游戏全长等价。

## 进度与安装保护

保留 `org.farshore.fishing.preview`、原应用名称、Godot用户目录、`save.json` / `save.backup.json`、schema2和schema1兼容逻辑，旧鱼、竿、饵、地区标识不重排。新版计划versionCode7 / 1.3.0，但发布必须同时验证原签名证书。
