# 远岸钓记 1.1 · 界面重设计

## 设计与实际实现

- 首次正常进入即为可玩的完整风景，不再每次显示阻挡游戏的说明页
- 删除所有装饰性英文眉题、品牌栏和诗意口号；页面标题为旅行、图鉴、收藏、行囊、钓获、设置
- 顶部地点与钓点、右侧资源、左下当前鱼饵、右下固定操作区。战斗隐藏侧边菜单并显示紧凑的张力/收线刻度
- 图鉴计数与搜索筛选压缩到约四分之一屏内；钓获操作固定在底部，只有真实新纪录才显示标记
- 移除平涂多边形木板，使用已有绘制前景作为钓手的岸边支撑
- 用户 09:24 修订：HUD、导航和所有交互采用无底色、无边框的原创图标 + 文字；抛竿使用鱼竿图标，提竿/收线切换为鱼钩/线轮图标
- 原创透明绘制旅行钓手、动态鱼竿与船钓木船；湖岸、港口、峡湾、海岸、密西西比、长江及单钓点美术使用实际资源
- 旅行页风景插画与无底色的图标式钓点选择；图鉴双列插画、搜索、地区/发现筛选和排序
- 详情使用自然标本图版、放大插画、独立最大长度/重量真实纪录；六格收藏展示
- 行囊使用独立装备插画、无底色文字动作、能力标注与原创饵料图标；鱼饵无限补给
- 钓获页突出鱼身、长度/重量、新发现与个人纪录。尺的左右端按实际鱼图透明边界与适配缩放计算，与吻端、尾端对齐
- 中华鲟等保护鱼只显示放归；失败保存仍可重试，未保存时退出受保护，存档层同时拒绝出售
- 通知出现在当前页面固定标题下方，避免装备/解锁失败提示被覆盖页遮挡

## 保持的接口与行为

保持 Main 的游戏输入、导航、存档与测试入口。所有经济、解锁、装备、收藏和设置操作仍使用深复制候选状态与唯一存档写入口。没有修改当前安装的正常玩家数据来解锁内容。目录数量来自内容目录，无 32 种或 4 水域硬编码。

`icon_action.gd` 承担无底色图标文字控件及透明触控区（最小 96 逻辑单位）；`ui_art.gd` 缓存与绘制 25 个实际生成的 512×512 RGBA 图标，不绘制矢量替代图形；`measure_ruler.gd` 承担实际标尺；`scenery_view.gd` 承担风景、钓手/船和鱼竿反馈。没有 WebView 或新增网络功能。页面使用轻浅的整页风景水彩；不绘制按钮、HUD 或内容卡片底板。文字以细描边和轻微阴影保证直接置于风景上的可读性。

## 验证

- Godot 4.6.3 官方 Compatibility 原生运行，设计坐标 720 × 1280；桌面运行截图实际视口 450 × 800
- 真实视觉审查覆盖 12 钓点、双列图鉴、详情、放大、六格收藏、装备、设置、咬钩、收线、一般结果、鳄雀鳝结果与中华鲟保护结果
- 图鉴 44/44、全部旅行解锁与示例纪录的截图来自 `tests/visual_audit.gd` 的独立开发存档，只用于展示，不是正常新玩家进度。测试目录排除在发行 APK 外
- 最终生成图标与专业布局版本的核心、存档和 UI 回归结果由独立测试流程更新，见 CORE_TESTS.md、SAVE_TESTS.md、UI_STYLE_TESTS.md。此前版本的通过结果不自动证明本次修改
- Android 导出、设备检查由独立构建流程记录；桌面截图不冒充 Android 真机证据
