# 1.2 全鱼种 3D 改造范围与验收

本轮范围现为现有44种鱼全部改为可玩的真实3D模型。保留六地区、十二钓点、成长装备与既有存档；不再以只含两种鱼的试钓版作为本轮最终交付。

## 制作分组

- 已有基准：鲤鱼、鳄雀鳝，保留独立模型与动画
- 特殊体型：中华鲟、牙鲆、欧洲鲽，检查骨板/腹侧口、左右眼侧、盲侧色彩、扁平身体与鳍缘
- 鲶形及长鳍鱼：斑点叉尾鮰、扁头鲶、南方鲇、长吻鮠、弓鳍鱼、乌鳢；须数、头宽、脂鳍、背臀鳍长度与裸皮/鳞片需分别处理
- 北方海鱼与巡游鱼：大西洋鳕、青鳕、绿青鳕、黑线鳕、大西洋狼鱼、日本竹荚鱼、日本鲭、大西洋鲭、大西洋鲱
- 其他淡水/细长体型：欧洲鲫、拟鲤、红眼鱼、河鲈、白斑狗鱼、欧鳊、丁鱥、长吻雀鳝、鳡
- 鲈形/鲷科/近岸鱼：真鲷、黑鲷、日本花鲈、日本沙鮻、褐菖鲉、大口黑鲈、鳜、欧洲海鲈、金头鲷、黑尾海鲷、白海鲷、环尾海鲷、红须鲷、字纹鮨、绯小鲷

共享骨架与制作工具不等于共享外形：各物种必须有独立头部/嘴形、体高/体宽/吻部比例、鳍布局、尾形与关键辨认特征。不得只换贴图颜色冒充不同鱼种。先审查代表性复杂体型，再批量制作相近体型。

## 运行时

`Fish3DRegistry` 与 `data/fish_3d.json` 声明全部44种的独立GLB路径。声明是交付要求，并不代表文件已经完成。缺失资产必须报告，不可悄悄显示另一种鱼。最终版启动、构建与测试都要求44种完整可加载。

所有模型为真实网格、蒙皮与骨骼动画；头朝 +X，Godot上方向 +Y，静止总长归一化为1米。四个动画为游动、挣扎、出水、展示，场景控制真实世界中的鱼体轨迹和尺寸。钓获详情使用独立透明3D展示窗口，图鉴列表可继续保留低成本原插画缩略图。

六种环境使用原有地理/钓点数据，3D基础构件按湖泊、港岸、峡湾、暖海、河湾、宽河等环境生成；仅保留一个当前活动环境。旅行操作不允许打断抛竿、搏鱼或尚未结算的起鱼流程。

## 必须达到的验证条件

1. 44份物种GLB、可编辑Blender源文件、制作参数/脚本与来源记录齐全
2. 每份模型有真实蒙皮、正确权重、四套可播放动画、无突兀循环跳变或根节点漂移
3. 逐种实际渲染检查正侧面、上下侧及关键动作；特殊鱼须额外检查不对称结构
4. 全44种通过既有地区/钓点/鱼饵/装备与落点规则可达；中华鲟继续保护观察、强制放归，不可出售
5. 所有六地区十二钓点均可在真正3D场景中进入并完成流程；保存、暂停、返回和重复操作不丢统计或重复奖励
6. 正常人体四肢/服装轮廓，五款鱼竿与八类饵料；真实触摸滑动和点击/拖动冲突回归
7. 最终冻结源码与独立备份逐文件核验，通过后仅从隔离副本导出。签名和私密材料不得进入源码或发布包
8. 分开记录静态/逻辑测试、桌面Godot渲染、安卓模拟器及实体手机证据；不得将软件渲染器结果描述为骁龙8 Elite的帧率保证

最终发布仅在以上范围完成并验证后进行，保留既有GitHub版本，不覆盖原发布物。
